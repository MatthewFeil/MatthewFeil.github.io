Opening an MP3 File

Open an MP3 file stored on your device. Transcribe processes audio locally.

  1. Select Open audio at the top of Transcribe and choose an MP3 file from your device. The demonstration shows the loaded file without opening the system file dialog.

Alternative: Drop an MP3 file onto the waveform area to open it.

The guide uses example.mp3: “On Hold for You” by Kevin MacLeod (incompetech.com), licensed under CC BY 4.0. The recording is unchanged; the guide displays waveform and spectrum data derived from it. Download it to follow along in Transcribe.

Playback Controls

Use the playback button in the bottom transport row to start and pause the recording.

Select an instruction to start the demonstration at that step.

  1. Select Play in the bottom transport row. The playhead indicates the current position in the waveform.

  2. Select Pause to hold the current position. Select Play again to resume.

Shortcuts: In Transcribe, press Space to play or pause when you are not editing a field. Use ← / → to seek two seconds, or hold Shift to seek five seconds.

Next: Timeline Navigation →

Timeline Navigation

Use the overview to navigate the recording, then select a playback position in the detailed waveform.

Select an instruction to start the demonstration at that step.

  1. Drag the visible-range window in the overview horizontally. The detailed waveform scrolls without changing the playback position.

  2. Click or tap a position in the waveform to move the playhead. A click without dragging does not create a selection.

  3. Select Play to start playback from the selected position.

Other navigation methods: While zoomed in, keep the mouse pointer near the left or right edge of the waveform to scroll. On touchscreens, drag the waveform with two fingers to pan.

Selection and Looping

Select a passage in the waveform to define a playback range. Selection only limits playback to this range, and Repeat enables continuous looping. You can create a selection during playback.

Select an instruction to start the demonstration at that step.

  1. Drag across the waveform from the start to the end of the passage. Release to set the highlighted range.

  2. Dragging a selection automatically enables Selection only and Repeat. Keep both enabled to loop the selected passage.

  3. If playback is paused, select Play. During playback, the playhead returns to the selection start each time it reaches the end of the range.

Adjusting the range: Drag either highlight boundary to change it. You can also set the start and end at the playhead with [ and ]; enable Repeat separately when using these keys to create a loop. Press B to return to the selection start when Selection only is enabled.

Next: Playback Speed →

Playback Speed

Adjust playback speed while the selected passage loops. Playback does not need to be paused.

Select an instruction to start the demonstration at that step.

  1. Select a playback speed. Values below 100% slow the recording while the loop continues. Keep Pitch lock enabled in Controls → Sound to preserve the original pitch.

  2. Select 100% to restore the recording’s original playback speed.

Alternatives: Use Other to enter a custom speed, then press Enter to apply it. Press , or . to move to a lower or higher speed preset.

For Pitch lock and other sound settings, see Sound settings in the user guide.
