# Matthew Feil's website

This repository contains my personal website at [matthewfeil.com](https://matthewfeil.com). I use it to share projects, posts, and tools related to my interests in music and technology.

The site is built with Jekyll and includes custom layouts, styles, and interactive pages such as calculators and a music transcription workbench.

## Run locally

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

Open [http://localhost:4000](http://localhost:4000) to view the site.
